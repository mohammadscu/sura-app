# تطبيق سورا — Sura app

A small page that opens the **SURA OPS** system (Sura Travel & Tourism) full screen, as an app with a home-screen icon.

- It keeps the sign-in (up to the system's limit) and the person's settings on the device — an iPhone otherwise forgets them each time the browser is left.
- It holds **no data and no passwords**: everything stays in the SURA OPS system, which still asks for the personal sign-in code.
- Open: https://mohammadscu.github.io/sura-app/
